# poke-ter Controls Guide

This guide maps all keyboard inputs, user interactions, and game controls supported in both overworld exploration and stateful battle interfaces.

---

## 1. Overworld Exploration Controls

| Key / Control | Action | Details |
| :--- | :--- | :--- |
| **Arrow Keys / WASD** | Walk | Navigates the trainer in the 4 cardinal directions. |
| **Space / Enter / Z** | Interact | Initiates dialogues with NPCs, advances text pages, and selects starter Pokémon. |
| **Escape / M** | Toggle Menu | Opens and closes the main game menu (Pokédex, Party, Bag, Save Game). |

---

## 2. Main Game Menu Operations

*   **Pokedex**: Displays the unique species successfully collected by the trainer during their journey.
*   **Pokemon Party**: Opens the active party list displaying current HP, levels, and moves. Lets you inspect, heal, or reorganize your team.
*   **Bag**: Views your active adventure item quantities (Poké Balls, Great Balls, Potions).
*   **Trainer Card**: Views your name, starter selection status, and current zone location.
*   **Save Game**: Executes a manual save of all progress to local storage.

---

## 3. Battle Interface Controls

*   **Mouse Clicks**: All selections inside the Battle UI panel (Fight, Bag, Pokémon, Run) are conducted via mouse selection.
*   **Dialogue Advance**: Press Space, Enter, or Click on the battle status box to advance status messages during move execution.
